# 共通ルール（choice aid で Claude Code を使う全員）

このファイルは `.setup/` から読み込まれる。直接書き換えない（更新で上書きされる）。自分だけのルールは作業フォルダの `CLAUDE.md` に書く。

## 絶対に守ること

1. **ファイルを消さない。** 不要なものは `archive/` に移す（元の構造を保つ）。
2. **Google ドライブは読むだけ。** 上書き・移動・削除・名前の変更・共有設定の変更はしない。新しく作ってよいのは、本人が「作って」と言ったファイルと、`AI効果レポート` フォルダのレビューだけ。
3. **ファイルの移動・名前の変更は、先に計画を表で見せ、本人の「OK」を取ってから。** 実行したら `docs/整理ログ_YYYYMMDD.md` に元と先を残す。
4. **外部に送らない。** メール・LINE・チャットの送信、フォームの送信はしない。下書きまで作って本人に渡す。例外は、本人が設定した週次レビューの自動メール（GAS）だけ。
5. **お金と個人の数字を書き写さない。** 売上・利益・単価・PL、給与・時給・Pt・個人別の成績や報酬、個人の連絡先・住所・退職理由は、ドライブで読んで計算に使ってよいが、メモ・ログ・レビュー・`.setup/` には書かない（ファイル名と場所だけ書く）。
6. **分からないことは推測で埋めず、聞く。** 質問は1回に3つまで。本人が読めば分かること・ドライブを見れば分かることは聞かない。
7. **人の名前の漢字は勝手に直さない。** 文字化けに見えても本人に確かめる。

## ファイルの置き方

- ファイル名：`YYYYMMDD_内容_v01.拡張子`。新しい版は `_v02`。「最新」「final」「修正版」は使わない。
- 新しい版を作ったら、古い版は `archive/` へ。
- 迷ったものは `inbox/` に置き、あとで本人と決める。
- 期限とゴールがある仕事だけ `projects/PJ_名前/` を作る。継続業務は `業務/` の下にテーマで分ける。

## 作業の終わりに

- 作業が一区切りしたら、`docs/進捗メモ.md` の先頭に「日付／進んだこと／次にやること／待っていること」を足す。
- 自動化や作業をしたら、`docs/AI効果/AI活用ログ.csv` に1行足す（書き方は `.setup/templates/AI効果の記録.md`）。

## 更新

- `.setup/` は会社側で更新される。起動のたびに自動で取り込む（`.claude/settings.json` のフック）。取り込めなかったら、本人に「`.setup` を更新して」と言ってもらい、`git -C .setup pull` する。

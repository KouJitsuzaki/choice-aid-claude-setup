# choice aid Claude Code セットアップ

choice aid のメンバーが Claude Code を使い始めるためのセットアップ一式です。
このページのURLを受け取った人は、下の **3つ** をやるだけで、あとは Claude が順番に進めます。

---

## あなたがやること（約15分）

### 1. Claude のデスクトップアプリを入れて、ログインする

- https://claude.ai/download から、パソコン（Windows か Mac）に合うものを入れる
- 案内されたアカウントでログインする

### 2. Google ドライブをつなぐ

1. Claude アプリの左下のアイコン → **設定** → **コネクタ**
2. **Google Drive** の「接続」を押し、**会社の Google アカウント**を選んで「許可」
3. **Google Sheets** があれば、同じように接続する

### 3. 作業フォルダを作り、Claude に1文を貼る

1. 「ドキュメント」の中に、仕事用のフォルダを1つ作る（例：`コネスト業務`）
2. Claude アプリの上の **Code** タブを開き、フォルダの選択で 1. のフォルダを選ぶ
3. 入力欄に、次の1文をそのまま貼って送る

```
次の手順でセットアップを進めてください：https://raw.githubusercontent.com/KouJitsuzaki/choice-aid-claude-setup/main/SETUP.md
```

あとは Claude が質問したり、計画を見せて「OK」を求めたりします。答えていけば終わります。

---

## 途中で気をつけること

- Claude が「このコマンドを実行してよいか」と聞いてきたら、内容を読んで許可してください。分からなければ「これは何をするの？」と聞き返して大丈夫です。
- Claude はファイルを消しません。ドライブのファイルも読むだけで、書き換えません（ルールと設定の両方で止めています）。
- 途中でやめても大丈夫です。同じフォルダで Code タブを開き「セットアップの続きをして」と言えば、続きから始まります。

## 更新について

このリポジトリが更新されると、次に Claude を開いたときに自動で取り込まれます（作業フォルダの `.setup/` に入っています）。

## このリポジトリについて

- 公開されています。売上・利益・給与などのお金の数字、個人の連絡先や成績は入れていません。業務の数字は、各自の Google アカウントの権限でドライブから読みます。
- 中身：`SETUP.md`（Claude が読む手順）、`context/`（部署ごとの業務の地図）、`rules/`（全員共通のルール）、`templates/`（作業フォルダに置くひな形）、`scripts/gas/`（週次レビューの自動メール）
